# LayoutGlow v0.6.0

Конвертация текста стала универсальной: выделение читается через UI
Automation без отправки Ctrl+C — конвертация теперь работает в MobaXterm
и любых других терминалах, где Ctrl+C означает SIGINT.

## Что нового

- **Выделенный текст читается без Ctrl+C.** Раньше первым шагом всегда
  шло «слепое» Ctrl+C: в неизвестных приложениях-терминалах (MobaXterm)
  это отправляло процессу SIGINT вместо копирования, и конвертация не
  работала. Теперь выделение читается через UI Automation
  (`TextPattern.GetSelection`) — приложению вообще не отправляются
  клавиши. Поддерживают Блокнот, браузеры, Office, Electron-приложения.
- **Scintilla (Notepad++, SciTE) — безопасный fallback.** Если UIA-
  провайдера нет, выделение проверяется напрямую у контрола
  (`SCI_GETSELECTIONSTART/END`), и только при подтверждённом непустом
  выделении выполняется копирование через буфер (Ctrl+C с непустым
  выделением безопасен: это редактор, а не терминал).
- **Без списков «известных терминалов».** Класс окна больше не решает,
  как конвертировать: если выделения нет, конвертируется последнее
  набранное слово (стирание + вставка Shift+Insert) — этот путь работает
  в cmd, PowerShell, Windows Terminal, mintty, ConEmu, MobaXterm и где
  угодно ещё.
- **Запасной путь тоже без Ctrl+C**: если слово не отслежено (курсор
  передвинут мышью), синтезируется выделение (Ctrl+Shift+Left) и
  читается через UIA; если прочитать не удалось, выделение сворачивается
  обратно к курсору.

В остальном релиз совпадает с v0.5.0: пословная конвертация смешанного
текста (`привет vtldtlm` → `ghbdtn медведь`), автономная разблокировка
подсветки Bloody, версия в меню трея.

## Артефакт

| Параметр | Значение |
|---|---|
| Файл | `LayoutGlow.exe` — единственный, портативный |
| Размер | ~38,5 КБ |
| Платформа | Windows 10/11 x64 |
| Зависимости | .NET Framework 4.x (встроен в Windows) |
| Права | Администратор не нужен |
| Настройки | `LayoutGlow.ini` рядом с exe (создаётся автоматически, для работы не нужен) |

## Совместимость

- Клавиатуры: Bloody B180R (`VID_09DA&PID_FA14`) проверено; вероятно,
  другие Bloody поколения KeyDominator2 (B338R, B975 и т.п.). Без
  клавиатуры Bloody подсветку можно полностью отключить в меню трея —
  обращений к HID не будет.
- ⚠️ Не запускать одновременно с **Punto/Caramba Switcher** — конфликт
  по перехвату клавиш.
- KeyDominator2 не требуется: LayoutGlow сам разблокирует клавиатуру.
- **MobaXterm**: при вставке кириллицы показывает собственное
  предупреждение о «небезопасных символах» (paste confirmation) — это её
  штатная защита от homograph-атак; отключается в настройках терминала
  (кнопка Settings прямо в диалоге предупреждения).
- В приложениях, запущенных **от имени администратора**, конвертация
  не сработает, если LayoutGlow запущен без таких же прав (ограничение
  Windows UIPI).

## Известные ограничения

- Конвертация последнего слова опирается на отслеживание набранного
  текста: если слово было напечатано до запуска LayoutGlow или курсор
  передвинут мышью в середину другого текста, сработает запасной путь
  (синтетическое выделение) либо конвертация не выполнится.
- В приложениях без UIA-провайдера и без Scintilla (редкие старые
  редакторы) конвертация выделения недоступна — работает конвертация
  последнего слова.
- Двойной Shift на пустой строке (нет слова для конвертации) не
  переключает раскладку — осознанное поведение.
- В консолях раскладка отслеживается по хоткеям: если раскладку в консоли
  переключить мышью через языковую панель, индикация рассинхронизируется
  до следующего нажатия хоткея.
- Слово, смешивающее кириллицу и латиницу внутри (`привet`),
  конвертируется целиком в одну сторону — по наличию кириллицы.
- До входа в Windows (экран ввода пароля) подсветка погашена — это
  состояние прошивки после подачи питания; LayoutGlow включает её
  сразу после своего запуска.
