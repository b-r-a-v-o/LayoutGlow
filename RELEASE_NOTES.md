# LayoutGlow v0.4.0

Подсветка стала полностью автономной: LayoutGlow сам разблокирует
клавиатуру Bloody после её включения и больше не нуждается в
KeyDominator2. Включает все исправления v0.3.0.

## Что нового

### Автономная подсветка (главное)

- **Рукопожатие разблокировки клавиатуры.** Выяснилось (загрузочный
  захват USBPcap, 09.11.2026): после подачи питания прошивка Bloody
  игнорирует канал команд, пока хост не выполнит обмен
  «SetFeature + GetFeature» — после команд `1F`, `05`, `29`, `2A`, `2F`
  и `03 06 05` нужно вычитать ответ. Раньше это незаметно делал
  KeyDominator2 из автозагрузки, и LayoutGlow работал «поверх».
  Теперь рукопожатие встроено в init подсветки — KD2 не нужен вообще.
  Подробности в `docs/PROTOCOL.md`.
- **Восстановление после переподключения клавиатуры.** Приложение
  отслеживает `WM_DEVICECHANGE` (приход интерфейса HID и широковещательный
  `DBT_DEVNODES_CHANGED`) и автоматически повторяет рукопожатие после
  USB-глитча, сна/пробуждения или переподключения клавиатуры.
- **Версия в меню трея** (правый клик по иконке) и в тексте подсказки.

### Из v0.3.0 (конвертация текста)

- Notepad++/SciTE: корректная проверка пустого выделения через Scintilla
  (`SCI_GETSELECTIONSTART/END` = 2143/2145) — пустой Ctrl+C больше не
  копирует всю строку в буфер.
- Направление конвертации определяется по юникод-диапазону кириллицы
  (U+0410–U+044F, Ёё), а не по таблице `RuToEn.ContainsKey`.

## Артефакт

| Параметр | Значение |
|---|---|
| Файл | `LayoutGlow.exe` — единственный, портативный |
| Размер | ~37,5 КБ (38 400 байт) |
| Платформа | Windows 10/11 x64 |
| Зависимости | .NET Framework 4.x (встроен в Windows) |
| Права | Администратор не нужен |
| Настройки | `LayoutGlow.ini` рядом с exe (создаётся автоматически, для работы не нужен) |

## Совместимость

- Клавиатуры: Bloody B180R (`VID_09DA&PID_FA14`) проверено; вероятно,
  другие Bloody поколения KeyDominator2 (B338R, B975 и т.п.). Без
  клавиатуры Bloody подсветку можно полностью отключить в меню трея —
  обращений к HID не будет.
- ⚠️ Не запускать одновременно с **Punto/Caramba Switcher** — конфликт
  по перехвату клавиш.
- KeyDominator2 можно убрать из автозагрузки — LayoutGlow v0.4.0
  самодостаточен. Если KD2 запущен и в его окне меняют цвет, он
  перезапишет цвет своим профилем (LayoutGlow вернёт свой в течение
  5 секунд keepalive).
- В приложениях, запущенных **от имени администратора**, конвертация
  выделенного текста не сработает, если LayoutGlow запущен без таких же
  прав (ограничение Windows UIPI).

## Известные ограничения

- Конвертация последнего слова опирается на отслеживание набранного
  текста: если слово было напечатано до запуска LayoutGlow или курсор
  передвинут мышью в середину другого текста, сработает запасной путь
  (синтетическое выделение) либо конвертация не выполнится.
- Двойной Shift на пустой строке (нет слова для конвертации) не
  переключает раскладку — осознанное поведение.
- В консолях раскладка отслеживается по хоткеям: если раскладку в консоли
  переключить мышью через языковую панель, индикация рассинхронизируется
  до следующего нажатия хоткея.
- До входа в Windows (экран ввода пароля) подсветка погашена — это
  состояние прошивки после подачи питания; LayoutGlow включает её
  сразу после своего запуска.
