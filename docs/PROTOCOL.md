# Протокол подсветки клавиатур Bloody (поколение KeyDominator2)

Получено реверс-инжинирингом USB-трафика KeyDominator2 (USBPcap) на
Bloody B180R (`VID_09DA&PID_FA14`).

## Транспорт

- HID-интерфейс: `vid_09da&pid_<PID>&mi_02&col04`
  (у мыши Bloody PID другой — её трогать нельзя).
- Feature report, 64 байта, report ID = `0x07` (первый байт буфера).
- Отправка: `HidD_SetFeature` (USB SET_REPORT, wValue = `0x0307`,
  wIndex = 2, wLength = 64).

## Последовательность инициализации (34 пакета, пауза ~8 мс)

```
07 1F, 07 1F, 07 05, 07 1F, 07 1F, 07 1F, 07 29, 07 1F,
07 1F, 07 1F, 07 05, 07 07, 07 1F, 07 1F, 07 2A, 07 1F,
07 1F, 07 2A, 07 1F, 07 1F, 07 29, 07 1E 01,
07 09 00 00 00 00 00 00 01,
07 05, 07 2F 00 2E,
07 0C 00 00 00 00 00 00 06 80,
07 0C 00 00 00 00 00 00 06 80,
07 03 06 05, 07 06, 07 03 06 01, 07 03 06 05,
07 03 06 01, 07 03 06 02, 07 05
```

(каждый пакет дополняется нулями до 64 байт)

## Установка сплошного цвета

Достаточно **одного** кадра + коммита:

```
07 03 06 02 00 00 00 00 [R G B] × 18   ← 54 байта RGB-триплетов со смещения 8
07 05                                  ← коммит
```

После коммита прошивка **сама удерживает цвет** — непрерывный стриминг
не нужен (KeyDominator2 шлёт кадры только при смене цвета).

## Грабли, на которые мы наступили

1. Пакеты `07 03 06 01` / `07 03 06 00`, заполненные данными цвета,
   ломают кадр целиком — цвет не применяется вообще. Цвет живёт только
   в пакете `07 03 06 02`.
2. `HidD_SetFeature` возвращает успех, даже когда прошивка игнорирует
   кадр — проверять можно только глазами.
3. KeyDominator2, запущенный параллельно, перезаписывает цвет своим
   профилем — при отладке его надо выгрузить.
4. В захватах USBPcap payload control-передач может быть сдвинут
   на 1 байт (setup 8 байт + маркер направления).
