# LayoutGlow

Трей-утилита для Windows 10/11 x64: мгновенная конвертация раскладки текста
по двойному нажатию левого Shift + индикация активной раскладки подсветкой
клавиатуры Bloody (B180R и другие модели на контроллере `VID_09DA`).

## Возможности

- **2 × Left Shift** — конвертация выделенного текста EN ↔ RU
  (`руддщ` → `привет` и обратно). Если текст не выделен — конвертируется
  последнее набранное слово. После конвертации системная раскладка
  переключается, чтобы вы продолжили печатать правильно.
- **Конвертация слова без мерцания выделения** — приложение отслеживает
  набираемый текст и просто стирает слово и вставляет его обратно
  сконвертированным. Синтетическое выделение (Ctrl+Shift+Left) используется
  только как запасной вариант, когда слово не отслежено (например, курсор
  передвинут мышью).
- **Работает в консолях**: cmd, PowerShell, Windows Terminal, а также
  терминалы mintty (Git Bash) и ConEmu — там, где нет ни выделения, ни
  clipboard-копирования, слово конвертируется через стирание + вставку
  (Shift+Insert).
- **Подсветка по раскладке** — английская = зелёный, русская = красный
  (цвета настраиваются из меню трея). Прошивка клавиатуры сама удерживает
  цвет — приложение не гоняет трафик постоянно.
- **Иконка в трее** — зелёный/красный кружок показывает текущую раскладку;
  правый клик — настройки: включение/выключение конвертации и подсветки,
  выбор цветов, автозагрузка, выход.
- **Работает без клавиатуры Bloody** — если отключить подсветку в меню,
  приложение вообще не обращается к HID-устройствам.

## Артефакт

| Параметр | Значение |
|---|---|
| Файл | `LayoutGlow.exe` (единственный, портативный) |
| Размер | ~35 КБ |
| Платформа | Windows 10/11 x64 (работает и на x86) |
| Зависимости | .NET Framework 4.x — уже встроен в Windows 10 |
| Права | Администратор **не нужен** |
| Установка | Не требуется; настройки хранятся в `LayoutGlow.ini` рядом с exe |

> Примечание: конвертация выделенного текста работает через буфер обмена
> (Ctrl+C → преобразование → Ctrl+V), поэтому в приложениях, запущенных
> **от имени администратора**, конвертация не сработает (ограничение
> целостности Windows UIPI), если LayoutGlow не запущен с теми же правами.

## Настройки (LayoutGlow.ini)

```ini
ConvertEnabled=1        ; конвертация по 2xLShift (0/1)
BacklightEnabled=1      ; подсветка клавиатуры (0/1)
DoubleTapMs=600         ; окно двойного нажатия Shift, мс
SwitchLayout=1          ; переключать системную раскладку после конвертации
EnColor=0,255,0         ; цвет подсветки для английской раскладки (R,G,B)
RuColor=255,0,0         ; цвет подсветки для русской раскладки (R,G,B)
LogEnabled=0            ; отладочный лог в LayoutGlow.log рядом с exe (0/1)
```

Все параметры, кроме `DoubleTapMs`, также меняются из меню трея.

## Совместимые клавиатуры

Протокол подсветки идентичен тому, что шлёт фирменный KeyDominator2:
HID feature report 64 байта, report ID `0x07`, интерфейс `mi_02&col04`.
Проверено на **Bloody B180R** (`VID_09DA&PID_FA14`, определяется системой
как B338R). Вероятно, подойдут и другие Bloody того же поколения (B338R,
B975 и т.п.) — смотрите `docs/PROTOCOL.md`.

⚠️ **Не запускайте одновременно с KeyDominator2** — он непрерывно
перезаписывает цвет подсветки своим профилем.

⚠️ **Не запускайте одновременно с другими переключателями раскладки**
(Punto Switcher, Caramba Switcher и т.п.) — они перехватывают те же
нажатия Shift, и приложения мешают друг другу.

## Сборка из исходников

Ничего ставить не нужно — используется компилятор C#, встроенный в Windows:

```bat
build.cmd
```

или вручную:

```bat
%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe -nologo -target:winexe ^
  -out:LayoutGlow.exe src\LayoutGlow.cs ^
  -r:System.Windows.Forms.dll -r:System.Drawing.dll
```

## Структура репозитория

```
src/LayoutGlow.cs   — весь исходный код (один файл, C# 5-совместимый)
build.cmd           — сборка двойным кликом
build.ps1           — та же сборка из PowerShell
docs/PROTOCOL.md    — описание реверс-инжиниринга протокола подсветки
```

## Как это работает

- **Конвертация**: низкоуровневый хук клавиатуры (`WH_KEYBOARD_LL`) ловит
  двойной отпуск LShift. Выделенный текст конвертируется через буфер
  (Ctrl+C → таблица соответствия клавиш EN↔RU → Ctrl+V, буфер
  восстанавливается). Последнее слово — через трекинг набранного текста
  (`ToUnicodeEx`): стирание бэкспейсами и вставка сконвертированного
  (Shift+Insert — работает и в терминалах, в отличие от Unicode-инъекции).
- **Трекинг слова**: хук складывает печатаемые символы в буфер; пробелы,
  стрелки, смена окна и клики мыши (`WH_MOUSE_LL`) буфер сбрасывают —
  поэтому после конвертации повторный 2×Shift конвертирует слово обратно.
- **Детекция раскладки**: `GetKeyboardLayout` потока foreground-окна с
  антидребезгом (2 стабильных опроса по 100 мс). Консольные окна
  отдают `HKL=0` и игнорируют `WM_INPUTLANGCHANGEREQUEST`, поэтому для них
  раскладка отслеживается по системным хоткеям (Ctrl+Shift / Alt+Shift /
  Win+Space), а переключается отправкой настоящей комбинации из реестра
  (`HKCU\Keyboard Layout\Toggle`).
- **Подсветка**: `HidD_SetFeature` на vendor-интерфейс клавиатуры —
  init-последовательность из 34 пакетов, затем одиночный кадр
  `07 03 06 02` с RGB-триплетами и коммит `07 05`; keepalive раз в 5 с
  на случай переподключения клавиатуры.
